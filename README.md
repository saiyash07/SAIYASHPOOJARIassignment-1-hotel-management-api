- bcryptjs
- express-session

## 🔌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Welcome message |
| POST | `/register` | Register a new user |
| POST | `/login` | Login |
| POST | `/hotels` | Add a hotel |
| GET | `/hotels` | Get all hotels |
| GET | `/hotels/:id` | Get hotel by ID |
| PUT | `/hotels/:id` | Update hotel |
| DELETE | `/hotels/:id` | Delete hotel |
